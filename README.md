# Video RAG on TVBench

A Video RAG project using **TVBench** and **Qwen2.5-VL-3B-Instruct** for video question answering.

### Current
- TVBench dataset setup
- Qwen2.5-VL baseline
- 20-question evaluation
- OpenCV-based frame sampling

### Next
Build a **temporal Video RAG pipeline** to retrieve relevant video segments before answering questions.

**Status:** Work in Progress
